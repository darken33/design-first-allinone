# Implementation Plan: Hello API Node.js — AsyncAPI Event-Driven Architecture

**Branch**: `002-hello-api-eda` | **Date**: 2026-04-29 | **Spec**: [spec.md](spec.md)
**Input**: Extension de l'API REST `001-hello-api-node` avec publication d'événements Kafka via contrat AsyncAPI 3.0

## Summary

Ajouter une couche de publication d'événements Kafka à l'API REST Hello Node.js existante, en
respectant le contrat AsyncAPI 3.0 (`hello-asyncapi-3-full.yaml`). Chaque appel REST valide
(`GET /api/v1/hello`, `GET /api/v1/hello/:name`) publiera un événement `HelloMessagePayload` sur le
topic `event.hello.v1`. Le code TypeScript du payload sera généré automatiquement depuis la spec
AsyncAPI via `@asyncapi/modelina`. L'architecture suit le pattern Adapter/interface pour isoler
`kafkajs` de la couche domaine, permettant le mock complet dans les tests unitaires.

## Technical Context

**Language/Version**: TypeScript 5.x + Node.js 20 LTS
**Primary Dependencies**: Express.js (existant) + `kafkajs` v2 + `@asyncapi/modelina` (codegen)
**Storage**: N/A (stateless, Kafka uniquement — pas de base de données)
**Testing**: Jest + Supertest (existants) + `bitnami/kafka` Docker image pour intégration
**Target Platform**: Linux server (Docker/Kubernetes)
**Project Type**: Web service REST (extension EDA)
**Performance Goals**: Overhead publication événement < 100 ms ; latence REST totale < 120 ms p99
**Constraints**: Fail-fast (aucun retry Kafka) ; /health indépendant de Kafka ; types générés non commités
**Scale/Scope**: Demo DevFest Nantes — un seul topic, un seul producteur, charge légère

## Architecture Decisions

### AD-001: AsyncAPI Codegen — `@asyncapi/modelina`

Generates TypeScript model classes from AsyncAPI schemas only (no server boilerplate).
Invoked via `npm run generate:events` → outputs to `src/generated/events/`.
See [research.md §1](research.md).

### AD-002: Kafka Client — `kafkajs` v2

Native TypeScript, async/await, well-maintained. Producer lifecycle managed in `src/index.ts`
(connect) and `src/shutdown.ts` (disconnect).
See [research.md §2](research.md).

### AD-003: Dependency Injection — Constructor + `IEventProducer` interface

No DI framework. `KafkaProducerAdapter` implements `IEventProducer`. `HelloService` receives it
via constructor. Tests inject a `jest.fn()` mock.
See [research.md §3](research.md) and [contracts/service.md](contracts/service.md).

### AD-004: Test Kafka — `bitnami/kafka` KRaft, `docker-compose.test.yml`

Single-container Kafka (no Zookeeper), separate from application `docker-compose.yml`.
See [research.md §4](research.md).

### AD-005: Fail-fast, no retry

Any Kafka error during `sendHelloMessage()` throws immediately → HTTP 500 `ApiErrorResponse`.
No retry, no backoff. Decision from spec clarification Q3.

### AD-006: `/health` independent of Kafka

Health probe always returns HTTP 200 if the Node.js process is running.
Kafka state is logged but never surfaced to K8s liveness probe.
Decision from spec clarification Q1.

## Implementation Steps (ordered)

1. **Install deps**: `npm install kafkajs` + `npm install --save-dev @asyncapi/cli`
2. **Add `generate:events` script** to `package.json` (modelina CLI)
3. **Run codegen** → verify `src/generated/events/HelloMessagePayload.ts`
4. **Create `IEventProducer` interface** at `src/services/interfaces/event-producer.interface.ts`
5. **Create `KafkaProducerAdapter`** at `src/adapters/kafka/kafka-producer.adapter.ts`
6. **Extend `HelloService`** — add constructor param, await `sendHelloMessage()` in `sayHello()`
7. **Update `src/index.ts`** — instantiate adapter, connect, wire into `HelloService`
8. **Update `src/shutdown.ts`** — call `kafkaProducer.disconnect()`
9. **Unit tests** — update `hello.service.spec.ts` with mock `IEventProducer`, all branches
10. **Create `docker-compose.test.yml`** with `bitnami/kafka` KRaft
11. **Create `tests/integration/hello-events.spec.ts`** — end-to-end Kafka publish verification
12. **Update `.gitignore`** — confirm `src/generated/` excluded
13. **Update `.env.example`** — document `KAFKA_BROKERS`, `KAFKA_CLIENT_ID`, `KAFKA_TOPIC_HELLO`
