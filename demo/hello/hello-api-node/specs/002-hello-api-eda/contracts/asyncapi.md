## Channel: `event.hello.v1`

**Address**: `event.hello.v1`
**Protocol**: Kafka
**Server**: `localhost:9092` (dev) | `$KAFKA_BROKERS` (production)
**Role**: Hello API Node.js is **producer only**

---

## Operation: `sendHelloMessage`

**Action**: `send` (producer)
**Description**: Published after every successful greeting response (HTTP 200)
**Trigger**: Once per valid `GET /api/v1/hello` or `GET /api/v1/hello/:name` request

## Publication Rules

| Condition | Event Published |
|-----------|----------------|
| `GET /api/v1/hello` → HTTP 200 | ✅ Yes — `{ "message": "Hello World" }` |
| `GET /api/v1/hello/:name` → HTTP 200 | ✅ Yes — `{ "message": "Hello <name>" }` |
| Validation error → HTTP 400 | ❌ No |
| Kafka error → HTTP 500 | ❌ No (publish attempted, failed) |

---

## Error Behaviour

- **Kafka unavailable**: `producer.send()` throws → propagated as HTTP 500 `ApiErrorResponse`
- **No retry**: fail-fast, no backoff, no dead-letter queue
- **At-most-once delivery**: no transaction, no exactly-once guarantee
